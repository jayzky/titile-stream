# TiTile-Stream

TiTile-Stream 是一个面向多光谱遥感影像的轻量级云原生动态瓦片分发与实时波段代数微服务。

## 背景与设计动机

传统遥感数据管理与出图流程存在以下典型痛点：
- 预先切片存储开销巨大：对海量多时相栅格影像（如 Sentinel-2、Landsat-8）预先烘焙瓦片金字塔（XYZ Tiles）会消耗数十倍存储空间。
- 动态指数计算灵活性差：用户计算不同植被指数（如 NDVI、NDWI、EVI）通常需要离线写脚本批处理重采样，无法在 WebGIS 前端实时调参预览。
- 重型 GIS 服务器运维成本高：传统 GeoServer / ArcGIS Server 依赖复杂 JVM 或庞大宿主环境，难以在轻量容器或边缘环境弹性伸缩。

TiTile-Stream 采用云原生理念，按需窗口化读取切片范围并依托安全 AST 引擎实时解算波段代数公式，实现即时分发。

## 系统架构

```
[ WebGIS 客户端 (Cesium / Leaflet / Mapbox) ]
                      │ 请求瓦片: /tiles/{z}/{x}/{y}/calc?expr=(B8-B4)/(B8+B4)
                      ▼
[ TMS Coordinate Math ] ──> 瓦片坐标 (Z, X, Y) 转换为 EPSG:3857 经纬度 Bounding Box
                      │
                      ▼
[ 安全 AST 波段代数引擎 ] ──> 语法树解析与变量白名单审查 (防止注入攻击)
                      │
                      ▼
[ 矢量化矩阵解算 (NumPy) ] ──> 浮点指数运算、异常值平滑与区间裁剪 [-1.0, 1.0]
                      │
                      ▼
[ 动态瓦片流式输出 ] ─────> 返回统计指标 JSON 或按需渲染热力色带 PNG 瓦片
```

## 核心特性

- 安全 AST 波段代数：基于 Python `ast` 模块遍历语法树节点，严格限制算子范围与白名单波段（`B1`-`B12`），彻底杜绝恶意代码注入。
- 零预切片存储：按需流式计算并返回瓦片，大幅节省云端存储空间。
- 精准瓦片坐标几何换算：内置标准 Web 墨卡托投影算法，支持快速计算瓦片边界。
- 便捷可视化调试面板：内置 `src/service/viewer.html`，支持即时预览公式输出的热力瓦片与数值分布。

## 常用指数示例

- 归一化植被指数 (NDVI): `(B8 - B4) / (B8 + B4 + 1e-6)`
- 归一化水体指数 (NDWI): `(B3 - B8) / (B3 + B8 + 1e-6)`
- 增强型植被指数 (EVI): `2.5 * (B8 - B4) / (B8 + 6.0 * B4 - 7.5 * B2 + 1.0)`

## 快速开始

### 运行测试

```powershell
pytest -v
```

### 启动服务

```powershell
uvicorn src.service.app:app --host 0.0.0.0 --port 8000
```

打开 `src/service/viewer.html` 即可交互式调试波段代数算子与瓦片渲染。
